Install TFT Panel

Firmware {{VERSION}} for the three supported screens.

Which screen do you have?

The installer sees the chip, not the screen, and two of these three answer to the same one — so it asks instead of guessing and leaving a panel dark. Other screens are not supported, even look-alikes with the same chip and display controller: see other boards.
  1. Use Chrome or Edge on a computer (Windows, macOS, Linux). Phones and Safari/Firefox cannot do this.
  2. Connect the panel's USB-C port to the computer with a cable that carries data.
  3. Pick your screen above, then click Connect and choose the serial port. The dialog that opens offers Install and names the screen you picked — a last chance to check it is the one in front of you. It takes about 3 minutes on the CrowPanel, about 1 minute on the ESP32-P4 boards.
    • CrowPanel: USB Serial / CH340 / usbserial
    • Waveshare: use the USB-C port USB 1.1 (not USB to UART); the port is USB JTAG/serial debug unit / usbmodem
    • VIEWE: USB Serial / CH340 / usbserial
  4. The panel restarts on its Wi-Fi setup screen: scan the first QR code with your phone to join it, then the second one to choose your Wi-Fi network.
This overwrites whatever is on the board, for good.
A demo firmware your screen came with cannot be downloaded again from anywhere. If you may want it back, save it first — one command, a few minutes, nothing written to the board: tools/backup-firmware.py --port <your port> from the repository. It copies the whole flash, writes the copy's sha256, then reads the board back to check the copy against it, and says so if the copy is not good. It also names your board, which is worth knowing before you answer the question above: a computer cannot tell the two ESP32-P4 screens apart. If a flashed panel stays dark, the firmware says WRONG BOARD on the USB serial console and names the image you need.

Choose your screen above, and the Install button appears here.

No serial port in the list?
CrowPanel on Windows: install the CH340 USB driver from WCH, then unplug and replug the panel (macOS and Linux already include it). The Waveshare needs no driver. Some USB-C cables only charge: try another one.
What happens next, screen by screen.
The guide's walkthrough shows the whole first start as a film: the setup screen, your Wi-Fi, the wait while it looks for your music, the first song.
After this, no cable needed.
The panel checks for new versions by itself and shows Update at the top of the screen: tap it to install. If an update ever fails to start, the panel goes back to the previous version. The user guide explains the rest.

TFT Panel is open source (MIT): github.com/r45635/tft-panel. It controls what you play on your music server and shows it: cover, synced lyrics, library, zones and volume.
